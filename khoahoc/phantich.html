Night Lens — Phân tích Reading & Listening

Copy prompt → nhờ ChatGPT phân tích từng đoạn → dán kết quả vào đây → có ngay trang trình chiếu để dạy và bản in PDF gửi học sinh.

1 Copy prompt

Chọn loại bài, copy prompt rồi dán vào ChatGPT / Gemini / Claude. Dán bài đọc hoặc transcript ngay bên dưới prompt và gửi đi.

Trình độ học sinh
Số mục mỗi đoạn
Xem / sửa prompt trước khi copy
Cách dùng:
  1. Bấm Copy prompt → dán vào ChatGPT.
  2. Xuống dòng cuối, dán bài Reading (hoặc transcript) rồi gửi.
  3. GPT trả về một khối JSON → bấm nút copy của khối đó → dán vào ô bước 2.
  4. Bài dài GPT trả lời làm nhiều lần: gõ tiếp, rồi dán tất cả các khối vào cùng một ô.

2 Dán kết quả

Dán nguyên câu trả lời của GPT (có thể dán nhiều khối JSON liền nhau). Bấm Hoàn thành để mở trang trình chiếu — bài tự lưu vào thư viện bên dưới.
