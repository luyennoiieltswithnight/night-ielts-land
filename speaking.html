⚙️ Cấu hình Groq API Key

  1. Vào console.groq.com/keys (miễn phí, không cần thẻ).
  2. Tạo API Key mới, copy chuỗi bắt đầu bằng gsk_... (chỉ hiện 1 lần).
  3. Dán vào ô bên dưới — key chỉ lưu trên trình duyệt này, chỉ gửi tới api.groq.com.
