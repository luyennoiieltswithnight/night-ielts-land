🐔 Vocabulary Game Generator

Dán danh sách từ vựng, chỉnh vài thiết lập, rồi tải về (hoặc copy) file game HTML để gửi cho học sinh hoặc đăng lên trang Night IELTS.

1 Thiết lập bài học

Tự động tạo theo tiêu đề — có thể sửa lại nếu muốn (nên giữ đuôi .html, chữ thường, không dấu, cách nhau bằng dấu gạch ngang để hợp với GitHub Pages).

2 Dán danh sách từ vựng

Mỗi dòng một từ. Hỗ trợ các cách phân tách: Tab (dán từ Excel/Google Sheets), từ - nghĩa, từ: nghĩa, hoặc từ, nghĩa. Dòng trống sẽ tự bỏ qua.

3 Kiểm tra & chỉnh sửa

English Tiếng Việt
Chưa có từ nào. Dán danh sách ở bước 2 rồi bấm "Phân tích danh sách".

4 Xuất game

Tải file về rồi kéo thả (hoặc upload) vào repo GitHub Pages của Night IELTS — mở trực tiếp bằng trình duyệt là chạy ngay, không cần build gì thêm. Cũng có thể gửi thẳng file .html này cho học sinh qua Zalo/Messenger để các em tự mở chơi.
Bấm "🧪 Xem thử ngay tại đây" để xem trước game với danh sách từ hiện tại.
