Nhập nhanh bằng văn bản

Dán toàn bộ nội dung đề (đã soạn theo đúng định dạng mẫu) vào ô dưới rồi bấm "Phân tích & Nạp vào form". Nếu chưa có nội dung, có 2 cách: (1) dùng AI ngay trong trang bằng Groq ở khung bên dưới, hoặc (2) bấm nút "Sao chép prompt mẫu" rồi đưa cho ChatGPT/Gemini/AI khác kèm tên đề (vd "Cambridge 17 Test 2").

🤖 Định dạng tự động bằng AI (Groq) — làm ngay trong trang, không cần copy qua lại

Dán đề GỐC (nguyên văn, thô, y như trong sách/PDF — đoạn văn + câu hỏi + đáp án nếu có) vào ô bên dưới. AI sẽ tự nhận diện đúng dạng của từng nhóm câu hỏi (True/False/Not Given, trắc nghiệm, chọn nhiều đáp án, matching heading, matching thông tin/tên riêng, điền từ vào đoạn văn, điền bảng/ghi chú...) và xuất ra đúng định dạng mẫu để nạp vào form — vì đề IELTS Reading có khá nhiều dạng câu hỏi và biến thể, không phải khuôn nào cũng giống nhau.

❓ Chưa có Groq API Key? Xem cách lấy (miễn phí, không cần thẻ)
  1. Vào console.groq.com/keys, đăng nhập (có thể dùng tài khoản Google) — nếu chưa có tài khoản thì đăng ký miễn phí.
  2. Bấm nút "Create API Key", đặt tên bất kỳ (vd "Night IELTS"), bấm Submit.
  3. Chuỗi key hiện ra (dạng gsk_...) — chỉ hiện đúng 1 lần, copy ngay và dán vào ô "Groq API Key" bên dưới.
  4. Gói miễn phí của Groq có giới hạn tốc độ (rate limit) nhưng đủ dùng để soạn đề — không cần nhập thẻ tín dụng.

Key chỉ lưu trong trình duyệt của bạn (localStorage), không gửi đi đâu ngoài api.groq.com. Model mặc định là openai/gpt-oss-120b (context dài, phù hợp đề nhiều câu) — có thể đổi sang model khác trên console.groq.com/docs/models nếu muốn.

Xem trước & Xuất bản

🚀 Xuất lên web (GitHub Pages)

Công cụ gọi thẳng GitHub API từ trình duyệt của bạn để tạo/cập nhật file — không qua máy chủ nào khác. Token chỉ lưu trong trình duyệt này (localStorage), không gửi đi đâu ngoài api.github.com.

Personal Access Token (PAT) là gì? Đây là một "mật khẩu riêng" GitHub cấp để cho phép công cụ này ghi file vào đúng 1 repo của bạn, thay vì dùng mật khẩu GitHub thật (an toàn hơn, có thể thu hồi bất cứ lúc nào).
Vì sao không điền sẵn token vào code luôn? Vì trang này (và mọi file trên GitHub Pages) là công khai — ai xem "View Source" cũng đọc được. Nếu gắn token thẳng vào code, bất kỳ ai cũng có thể lấy trộm token đó và ghi/xoá bất cứ gì trong repo của bạn. Token chỉ nên nằm trong trình duyệt của riêng bạn.
Tin vui: chỉ cần nhập một lần duy nhất — tick ô "Lưu lại" bên dưới (mặc định đã tick sẵn), lần sau mở tool lên là tự điền, không phải gõ lại.
Chọn quyền "repo" (hoặc với Fine-grained token: "Contents: Read and write" cho đúng repo bs-english-house) rồi copy token dán vào ô dưới.

📚 Quản lý đề đã lưu

Mỗi khi xuất bản thành công, công cụ tự lưu lại TOÀN BỘ nội dung đề (mọi passage/câu hỏi/đáp án) vào chính trình duyệt này — lần sau muốn sửa nhỏ rồi xuất bản lại, chỉ cần bấm "Mở lại" hoặc "🚀 Xuất bản lại" bên dưới, không cần dán lại prompt/nội dung từ đầu.

🌐 Tất cả đề đã xuất bản trên GitHub

Đọc thẳng từ reading/manifest.json trên GitHub bằng đúng Owner/Repo/Token đã nhập ở mục "6. Xem trước & Xuất bản" — danh sách này thấy được CẢ những đề cũ/lỗi đã tạo từ trước (kể cả từ máy khác), không phụ thuộc vào bản lưu trên máy này. Xoá ở đây là xoá vĩnh viễn khỏi GitHub Pages.
